1. ROZHODOVACÍ STROM (3 Otázky pro každý operátor)
-------------------------------------------------------------------
Otázka 1: KDO STOJÍ VLEVO OD OPERÁTORU?
- Náš objekt (např. ucet += 100, ucet1 == ucet2, ucet[0], ucet())
  --> Píše se jako METODA UVNITŘ TŘÍDY (v .h i .cpp)
- Cizí objekt / stream (např. std::cout << ucet)
  --> Píše se jako VNĚJŠÍ FUNKCE (mimo třídu, v .h se přidá 'friend')

Otázka 2: MĚNÍ TENTO OPERÁTOR MŮJ OBJEKT?
- ANO (Modifikační: +=, -=, =, ++, --)
  --> Návratový typ: Reference na sebe sama (MojeTrida&)
  --> Na konci těla v .cpp VŽDY: return *this;
- NE (Porovnávací, čtecí, aritmetické: ==, !=, <, +, -, [])
  --> Na konec hlavičky i definice napiš klíčové slovo 'const'
  --> Návratový typ:
      * Porovnání (==, !=, <)  --> bool
      * Tvorba nového účtu (+) --> Nový objekt hodnotou (MojeTrida)
      * Čtení prvku ([])       --> Typ prvku (např. double)

Otázka 3: KOLIK ARGUMENTŮ MÁ V ZÁVORCE (...) ?
- Pokud je to METODA UVNITŘ TŘÍDY:
  * Levý operand je skrytý (this), v závorce je o 1 méně:
    - Unární operátory (++, !)     --> 0 argumentů v závorce ()
    - Binární operátory (+, ==, []) --> 1 argument v závorce (const MojeTrida&)
- Pokud je to VNĚJŠÍ / FRIEND FUNKCE (<<, >>):
  * V závorce musí být OBA operandy:
    - Proudový výpis (<<)          --> 2 argumenty (std::ostream& os, const MojeTrida& obj)

2. PŘEHLED ZÁPISŮ VŠECH TYPŮ OPERÁTORŮ
===================================================================

[A] PROUDOVÝ VÝPIS (operator<<) - VŽDY NA ZKOUŠCE!
- Kde leží: Vně třídy / friend v .h
- Návratový typ: std::ostream&
- Parametry v závorce: (std::ostream& os, const MojeTrida& obj)
- Na konci těla VŽDY: return os;

[B] PŘIŘAZOVACÍ A MODIFIKAČNÍ (operator+=, operator-=)
- Kde leží: Uvnitř třídy
- Návratový typ: MojeTrida&
- Parametry v závorce: (double hodnota) nebo (const MojeTrida& druhy)
- Na konci těla VŽDY: return *this;

[C] POROVNÁVACÍ (operator==, operator!=, operator<)
- Kde leží: Uvnitř třídy
- Návratový typ: bool
- Parametry v závorce: (const MojeTrida& druhy) const
- Na konci těla: return true nebo false;

[D] ARITMETICKÉ SČÍTÁNÍ DVOJICE (operator+)
- Kde leží: Uvnitř třídy
- Návratový typ: MojeTrida (hodnotou - nový objekt!)
- Parametry v závorce: (const MojeTrida& druhy) const
- Na konci těla: return novyObjekt;

[E] INDEXOVACÍ (operator[])
- Kde leží: Uvnitř třídy
- Návratový typ: Typ prvku uvnitř pole/vektoru (např. double)
- Parametry v závorce: (size_t index) const
- Na konci těla: return pole[index];

[F] INKREMENT PREFIX A POSTFIX (operator++)
- Prefix (++a):  Návrat MojeTrida& | V závorce ()     | Na konci: return *this;
- Postfix (a++): Návrat MojeTrida  | V závorce (int)  | Na konci: return staryStav;

[G] VOLÁNÍ FUNKCE / FUNKTOR (operator())
- Kde leží: Uvnitř třídy
- Zvláštnost: První pár () je NÁZEV operátoru, druhý pár () jsou PARAMETRY.
- Bez parametrů: operator()()       --> zavolá se jako: ucet();
- S parametrem:  operator()(double) --> zavolá se jako: ucet(100.0);
- Návratový typ: void (nebo typ výpočtu podle zadání)

3. RYCHLÝ CHECKLIST PRO ZKOUŠKU
===================================================================
1. U operator<< NEZAPOMEŇ na 'friend' v .h a 'return os;' na konci.
2. U operator+= a operator-= NEZAPOMEŇ na 'return *this;'.
3. U čtecích operátorů (==, [], +) NEZAPOMEŇ na 'const' za závorkou.
4. U operátoru () nezapomeň, že se píší DVOJE ZÁVORKY ZA SEBOU: operator()(...).
